送信前

頻度・トークン・並列・推定文脈量・期限を制限する。質問を分割し、1件でも超過なら原文を切らず送信前に非対応とする。再試行も推定量を予約して同じ上限を適用。同期解析・描画は期限で強制中断できない。

再試行

上限付き指数バックオフ＋jitterで待つ。Retry-Afterより早く再送せず、初回込み1〜3試行。

並列とバッチ

独立質問をバッチ化し、並列・送信上限内で実行。

Mermaidの詳細モデルを表示
sequenceDiagram
    participant Adapter as CLI / HTTP / library caller
    participant Engine
    participant PDF as Snapshot / candidates / renderer
    participant Eval as Evaluator
    participant Control as Execution controller
    participant API as Jev
    Adapter->>Engine: PDF + validated schema + options
    Engine->>PDF: Build snapshot; prepare scoped source/images
    loop Dependency waves
        Engine->>Eval: Compatible independent question batches
        loop Each attempt within configured bounds
            Eval->>Control: Reserve request/tokens/cost; await admission
            Control-->>Eval: Permit or bounded failure
            Eval->>API: HTTPS request
            API-->>Eval: HTTP status + original body
            Eval->>Eval: Retain original body before validation
            opt Retryable and budget/deadline allows
                Eval->>Control: Wait exponential backoff + jitter / Retry-After
            end
        end
        Eval-->>Engine: Answers/errors + usage + original responses
        Engine->>Engine: Resolve source, validate, check provenance
    end
    Engine-->>Adapter: Partial report or error with received responses

起動と設定

run / serve共通の資源・送信制限と任意の描画featureは設定ガイドの起動設定を参照してください。

HTTP受付

上限はPDF 16 MiB・schema 1 MiB・options 64 KiB、期限30秒。実行中は429で拒否。

公開・隔離の設定

既定はループバック。外部待ち受け・Origin付き抽出はBearer必須。実APIの画像抽出は起動時に--allow-imagesを指定。TLS終端・不正PDF対策の隔離は運用側で用意する。

原文との対応

原文と正規化値を分け、同文でも位置が違えば別候補とする。部分調査で文書全体の不存在は断定しない。

レスポンスの保持

本文はUTF-8なら原文字列、それ以外はバイト列で保持。未知キー・検証失敗・再試行も残す。受信失敗・容量上限を示し、不完全・未受信ならbody_completeはfalse。

抽出できる条件

抽出には文字・座標が必要。文字コードと表示が異なるPDFは非対応の場合がある。

VOLTFILL · Best-effort PDF extraction · PDFへの書き込み、OCR、自動フォーム送信は現在の実装範囲外です。
入力・ページ上限は依存先の展開・予測復元の全メモリ確保を制限しません。不正PDFでメモリを使い切る可能性があり、プロセス隔離はありません。送信制御は同じコントローラー内だけに適用します。
